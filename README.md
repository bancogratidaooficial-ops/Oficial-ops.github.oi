# Escala 5x1 - Folguista da Madrugada

App para gerar escala 5x1 automática com folguista que só cobre noturno.

## 🚀 Como usar
1. Acesse: https://oficial-ops.github.io
2. Adicione funcionários e escolha o dia da folga
3. Clique em DEFINIR ESCALA QUE EU INSERI - NAO APAGAR MAIS
4. Clique em SALVAR DEFINITIVA

## 📱 Instalar como App
No Chrome: 3 pontinhos > Instalar app / Adicionar à tela inicial

## ✨ Funcionalidades
- Escala 5x1 automática (5 dias trabalha, 1 folga)
- Folguista da madrugada só cobre quando Mario folgar
- Encarregado folga Sab e Dom
- Salva automaticamente e não apaga mais
- Funciona offline
- Gera PDF pra imprimir

## 📂 Tipos
- 5x1 AUTOMATICO
- FOLGA FIXA
- ENCARREGADO
- FOLGUISTA MADRUGADA
- PERSONALIZADA

Feito para controle de escala de supermercado.
